# Jack Portfolio

A modern portfolio website built with [Astro](https://astro.build).

---

## 🚀 Getting Started

To run the project locally:

```bash
# 1. Clone this repo
git clone https://github.com/
cd Jack-Portfolio

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```
